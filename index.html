About this site

Dabom.org is the home of The Dabom Project. The program you can download here now is Danol, version 1.2.1.

Danol is a collection of games for Windows. You move with the keyboard, and the program speaks what is happening. You do not need to see the screen to play. Menus and spoken text are available in 9 languages.

This page is written in English and Korean. Use the language buttons at the top. Your choice is remembered on this computer.

Danol

Danol is for people who use a screen reader, or who prefer to play by sound and keyboard. Menus, moves, and results are spoken. Sound effects mark important moments.

What you can play

  • Board games, including janggi, chess, reversi, sudoku, and hex
  • Other games, including real baseball, battleship, blackjack, and code breaker
  • Sound and story games, including a rhythm game, sound quiz, and audio fiction

Languages

Danol supports 9 languages: Korean, English, German, French, Spanish, Russian, Chinese, Japanese, and Arabic.

How you use it

  • Windows application. No separate game controller is required.
  • Works with a keyboard. Screen readers such as SenseReader can be used with it.
  • After the first install, later updates can be installed from inside Danol.

다놀

다놀은 화면 낭독기를 쓰거나, 소리와 키보드로 놀고 싶은 사람을 위한 프로그램입니다. 메뉴, 수, 결과를 읽어 줍니다. 중요한 순간에는 효과음이 납니다.

어떤 놀이가 있나

  • 보드 게임: 장기, 체스, 리버시, 스도쿠, 헥스
  • 그 밖의 게임: 실전 야구, 배틀십, 블랙잭, 코드 브레이커
  • 소리와 이야기: 리듬 게임, 소리 퀴즈, 오디오 소설

언어

다놀은 9개 언어를 지원합니다. 한국어, 영어, 독일어, 프랑스어, 스페인어, 러시아어, 중국어, 일본어, 아랍어입니다.

어떻게 쓰나

  • Windows 프로그램입니다. 게임 컨트롤러는 필요 없습니다.
  • 키보드로 조작합니다. 센스리더 같은 화면 낭독기와 함께 쓸 수 있습니다.
  • 처음 설치한 뒤에는, 이후 업데이트는 다놀 안에서 받을 수 있습니다.

Accessibility

Danol is built around keyboard use and spoken feedback. This website follows the same idea.

This page

  • A skip link at the top goes to the main content.
  • Headings follow a single order. There is one page title, then section headings.
  • The language buttons say English and 한국어, and the page language changes with them.
  • Links name the file, the version, and the size. There are no pictures that carry the only instruction.

If something on Danol or on this page is hard to use with a screen reader, write to us. That report is useful.
